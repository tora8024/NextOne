# NextOne 維修台

電腦與設備維修單管理。店內人員可建立維修單、追蹤狀態、記錄檢測指令；客戶用獨立查詢頁看自己的進度。介面為繁體中文。

## Stack

- [Vite](https://vite.dev/) 8
- [React](https://react.dev/) 19 + TypeScript
- [React Router](https://reactrouter.com/) 7
- 資料存在瀏覽器 `localStorage`（鍵名 `nextone-repair-db-v1`），不需要資料庫或後端
- 字型：Noto Sans TC、IBM Plex Mono（隨套件打包）

第一次開啟會寫入示範資料。之後的新增與狀態變更都留在這個瀏覽器；側邊欄的「還原示範資料」會覆蓋本機修改。

## Run locally

需要 Node.js 20 或以上。

```bash
npm install
npm run dev
```

開發站點：<http://localhost:5173>

- 店內工作台：<http://localhost:5173/>
- 客戶查詢（沒有後台連結）：<http://localhost:5173/lookup>

正式打包與預覽：

```bash
npm run build
npm run preview
```

預覽站點：<http://localhost:4173>

## Features

1. **總覽**：設備總數（含類型分布）、客戶數、未結案張數，以及已受理 / 維修中 / 待取件 / 已完成的數量。
2. **建立維修單**：既有或新客戶（姓名、電話）、既有或新設備、硬體／軟體送修項目、客戶需求，以及指令或處理紀錄。
3. **追蹤**：列表可依狀態、客戶、設備與關鍵字篩選；維修單頁可改狀態、追加處理紀錄。客戶頁與設備頁各自列出相關維修單。
4. **客戶查詢**：輸入單號，或姓名加電話。只顯示狀態與標成「客戶可見」的說明，不顯示內部檢測指令，也進不了後台。

狀態變更會自動留下一筆客戶看得到的紀錄。手動紀錄預設為內部，需勾選才會出現在查詢頁。

## Project layout

- `src/pages/` — 總覽、維修單、客戶、設備、客戶查詢
- `src/lib/db.ts` — 讀寫、建立維修單、狀態與紀錄
- `src/data/seed.ts` — 示範資料
- `src/components/` — 後台版面、表格、狀態標籤
- `index.html` — 應用程式進入點
